# Ringkasan Soal Dart (Terpisah)

Folder ini berisi pemecahan soal menjadi 1 file per soal agar mudah dipahami dan dilaporkan.

## Daftar Soal dan File

1. List nama dan tampilkan semua nama  
   File: `soal_1_list_nama.dart`

2. Set buah dan tampilkan semua buah  
   File: `soal_2_set_buah.dart`

3. Input daftar pengeluaran dan hitung total  
   File: `soal_3_total_expenses.dart`

4. List kosong `days`, tambah 7 hari, lalu tampilkan  
   File: `soal_4_list_hari.dart`

5. Tambah 7 nama teman, filter nama diawali huruf `a`  
   File: `soal_5_filter_teman.dart`

6. Map profil (`name`, `address`, `age`, `country`), update country  
   File: `soal_6_map_profil.dart`

7. Map (`name`, `phone`), cari key dengan panjang 4  
   File: `soal_7_map_phone_filter_key.dart`

8. Aplikasi to-do sederhana (add, remove, view)  
   File: `soal_8_todo_app.dart`

## Cara Menjalankan

Jalankan dari root project:

```powershell
dart dart_exercises/soal_terpisah/soal_1_list_nama.dart
dart dart_exercises/soal_terpisah/soal_2_set_buah.dart
dart dart_exercises/soal_terpisah/soal_3_total_expenses.dart
dart dart_exercises/soal_terpisah/soal_4_list_hari.dart
dart dart_exercises/soal_terpisah/soal_5_filter_teman.dart
dart dart_exercises/soal_terpisah/soal_6_map_profil.dart
dart dart_exercises/soal_terpisah/soal_7_map_phone_filter_key.dart
dart dart_exercises/soal_terpisah/soal_8_todo_app.dart
```
